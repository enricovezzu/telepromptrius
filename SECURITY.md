# Security Policy

## Supported versions

Only the latest release receives fixes. The app updates itself automatically, and every update package is verified with an Ed25519 signature before it is installed.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's private reporting instead: open the **Security** tab of this repository and click **Report a vulnerability**.

Please include what you found, the steps to reproduce it, and the app version (shown in Telepromptrius → About Telepromptrius). You will get an answer within a few days. Fixes are published as a new release, and everyone receives them through the automatic update.
